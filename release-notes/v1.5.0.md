# Wallpaper Player v1.5.0

这是 v1.4.0 之后的设计系统升级版本：暗色玻璃拟态设计系统 v2 全量替换桌面端界面，并完成主进程重构收敛与发布前代码审查修复。

## 新增

### 暗色玻璃拟态设计系统 v2

- 桌面端界面全量重写：深空近黑底色 + 三组径向光晕氛围、玻璃质感卡片（`blur(22px) saturate(1.35)` + 顶部内高光）、青 → 靛渐变点缀。
- 覆盖侧栏、画廊、播放器控制条、设置面板、下载中心、AI 搜索与全部弹层；浅色主题同步反白适配。
- 圆角、阴影、动效统一三档缓出曲线，交互层次更柔和。
- 组件逻辑（React hooks / IPC）零改动，仅样式与布局结构变化。

### 插件入口

- 右侧栏活动栏底部新增"添加插件"按钮，点击直达"设置 → 插件管理"页。
- 设置面板支持初始定位到指定页面，关闭后自动复位，从其他入口打开时不受影响。

## 修复

- 修复 mpv 播放器字幕"显示/隐藏"开关失效：preload 未暴露 `mpvSetSubtitleVisible`，切换字幕轨后自动显示字幕与手动开关均静默无效，现补齐 preload 与类型声明。
- 修复三处未定义引用导致的运行时崩溃（远程服务、缩略图、右侧栏）。
- 手机端更新检查补 15 秒超时与 Abort 控制，APK 缺失时优雅降级提示。

## 重构与维护

- IPC 通道统一收敛到 `ipc-channels.js` 常量（唯一事实来源），remote IPC 注册合并。
- 主进程工具实现收敛：拆分 `download-manager` 与 `mpv` 模块，抽取 `exec` / `ip-utils` / `paths` / `portable-user-data` 共享实现。
- 网络资源解析与远程层收敛到共享实现。
- 前端 Context 与设置页精简，补充 electronAPI 类型声明与类型检查配置。
- 移除无发送方的 `thumbnail-progress` 死通道（缩略图为按需单张生成，无批量流程）。
- 接入 CI 验证流水线（前端构建 + Node 脚本 + electronAPI 类型检查 + 直接启动/插件注册/设置持久化验证）。
- 手机端工具函数去重：`stores/` 更名 `persistence/`，抽取 `utils/url.ts` 消除跨文件重复实现。

## 已知限制

- 沿用 v1.4.0：DRM 网站只能以内置网页方式观看；m3u8/mpd 支持播放但离线打包下载待接入；aria2 优先支持 BT v1 / btih 磁链。
- 缩略图按需懒生成，扫描阶段不展示逐张进度条。
- 手机端本次为代码同步（0.1.4），APK 未重新构建；如需要新的手机端 APK 可另行触发带 `publish-mobile-apk` 的发布。
