# Wallpaper Player v1.5.1

v1.5.0 的补丁版本，修复手机端批量打标签丢失旧标签、subst 映射盘/junction 环境下元数据缓存与扫描索引失效的问题。

## 修复

### 批量打标签丢失 legacy 标签

- 旧版本（1.4 及更早）以"原始路径字符串"作为标签存储键，而当前远程解析走 realpath 规范化；当两者路径不一致（Windows 上大小写不同、subst 映射盘、junction 目录等场景）时，手机端批量打标签会静默丢弃这些旧标签。
- 标签读写统一改为归一化路径匹配：先按路径键（`pathKey`）快路径匹配，未命中时按 realpath 归一化慢路径匹配，批量打标签、单视频设标签、库展示均兼容字面量与 realpath 两种历史键，迁移时保留全部旧标签。

### subst 映射盘 / junction 环境下元数据与扫描索引失效

- 视频元数据缓存键按 realpath 归一化：扫描器返回的路径是 realpath 后的，而探测入口可能收到字面量路径，映射盘下缓存永远未命中，扫描结果缺失编码/分辨率等媒体信息。
- 扫描索引路径同样按 realpath 归一化：扫描保存索引与调用方按字面量读取路径不一致时，索引文件永远找不到，重新打开视频库会丢失缓存扫描结果。

### 验证脚本健壮性

- verify 脚本生成的 ffmpeg fixture 统一显式等待完成，慢环境（CI 上 ffmpeg 被 Defender 扫描拖慢）下不再出现文件未生成就断言的竞态。
- 同步执行外部命令加 2 分钟超时，外部工具卡死时快速失败而不是让 CI 步骤无限挂起；脚本退出时显式清理目录监听并退出，避免句柄阻止进程结束。

## 验证

```powershell
npm run verify:remote-library
npm run verify:legacy-tags
npm run verify:video-metadata
```
