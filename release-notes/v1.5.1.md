# Wallpaper Player v1.5.1

v1.5.0 的补丁版本，修复手机端批量打标签时可能丢失旧版本文本标签的问题。

## 修复

### 批量打标签丢失 legacy 标签

- 旧版本（1.4 及更早）以"原始路径字符串"作为标签存储键，而当前远程解析走 realpath 规范化；当两者路径大小写不一致（如 Windows 上 `D:\a\_temp` 与 `D:\A\_TEMP`）时，手机端批量打标签会静默丢弃这些旧标签。
- 标签读写统一改为按归一化路径键（`pathKey`）匹配：批量打标签、单视频设标签、库展示均兼容字面量与 realpath 两种历史键，迁移时保留全部旧标签。
- 新增 `verify:legacy-tags` 回归验证并接入 CI，防止此类环境差异问题回归。

## 验证

```powershell
npm run verify:remote-library
npm run verify:legacy-tags
```
