# Wallpaper Player v1.5.2

本次发布整合桌面界面、播放器布局和后台任务管理的修复，并同步提交手机端优化源码。

## 桌面变化

- 接入渐变四宫格应用图标和流光开屏，支持重播、轻微视差与减少动态效果设置。
- 设置页在深色、浅色主题下均使用不透明底色，加强外层遮罩，避免画廊内容透入；打开设置时隐藏重播按钮。
- 修复播放器画面越过容器、缩放后覆盖控制栏的问题，保留暂停与跳转状态，改善窄窗口布局和键盘焦点。
- 设置首次读取、规范化和声明式插件设置准备移至后台，减少大视频库配置在主线程上的重复处理。
- 完善媒体查询、缩略图、下载、分析及转码任务的取消、并发预算和退出回收。
- 身份文件损坏或不可读时保留原文件，暂停手机访问并显示恢复提示；修复文件后可刷新恢复原身份，避免静默重置绑定。
- 加强 IPC 来源、媒体访问、设置恢复及插件生命周期校验。

## 手机端源码

- 改善视频库分页、连接与导航请求归属、播放器面板、手势和无障碍交互。
- 连接失败页提供更新入口，更新检查核对当前电脑、绑定及协议兼容性。
- 同步应用图标配置、依赖升级与已记录的兼容修补。

本次资产仅包含 Windows x64 安装包、便携版、自动更新元数据和三个配套官方插件。Android 正式签名与升级迁移仍待完成，因此不附新的 APK；现有手机端更新发现会继续检查兼容的历史发布。

Windows 可执行文件沿用当前未签名发布策略。真机手机长时性能、iOS 原生、部分 Windows 安装升级与多显示器矩阵仍在验收中，具体范围见仓库中的实施记录。
